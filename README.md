## Preview locally
Open `index.html` in a modern browser. An internet connection is used only to load the Google Fonts; the site itself has no build step or framework dependency.

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `mohamed-raihan-portfolio`).
2. Extract this ZIP file.
3. Upload the contents of the extracted folder to the **root** of the repository. Make sure `index.html` is at the repository root, not inside another nested folder.
4. On GitHub, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/(root)`, then click **Save**.
7. Wait for the deployment to finish. GitHub will display the live website URL in the Pages section.
